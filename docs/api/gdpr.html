create

POST /gdpr

Operation ID: accessErasure.

Authentication: credential (Access-Token) or credential (appId).

Request body

application/json

Property Type Required Description
subject_identities array of object No
subject_identities[].identity_format string Yes To be sent as "raw". Branch currently only supports "raw".
subject_identities[].identity_type enum: BROWSER_ID, DEVICE_ID, USER_ID, DEVELOPER_ID Yes The type of identity being sent. It can be "BROWSER_ID", "DEVICE_ID", "USER_ID", or "DEVELOPER_ID".
subject_identities[].identity_value string No The value as per the identity_type, IDFA, Google_advertising_id, etc.
subject_request_type enum: access, erasure Yes The type of post request being sent. In this case "access"
